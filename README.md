# 软萌大肥鱼

> 给 [DSH](https://github.com/deepseek-ai) 装一个「有身体、有记忆、会自己写日记」的抖音角色。
>
> **一个插件，装完就有。** 不是 AI 女友模板，是能跑起来的东西。

---

## 装

**方式 A：DSH 桌面版（推荐）**

设置 → 插件 → 从本地目录安装 → 选这个文件夹 → 重启 DSH。

**方式 B：命令行（有 dsh CLI 的话）**

```powershell
dsh plugin --profile desktop add link:<你克隆下来的目录>
```

装完**重启一次 DSH**。就这样。

> 完整说明看 **[说明书.md](./说明书.md)**，一步一步的看 [docs/安装指南.md](./docs/安装指南.md)。

## 插件只做三件事

1. 首次启动把 `assets/persona.md` 复制到 `<DSH_HOME>/douyin-duty/`（**已有就跳过，绝不覆盖**）
2. 起两个本地只读服务 —— **默认不起**（utoStart: false，见下）
3. 注册一个状态接口

**不碰的东西**：不改模型路由、不改任何会话、不改你 profile 的配置、不联网、不下载。

> ⚠️ 服务默认**不自动起**：重启 DSH 时你自己的生命状态可能还没起来，
> 插件抢先 bind 8781 会用空 state 顶掉你的。想让它起就设 utoStart: true。
每个可能抛错的地方都包了 try/catch —— **它挂了不会拖死 DSH**。
