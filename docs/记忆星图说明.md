# 记忆星图（brainviz）

把她记住的东西画成一张图：谁来过、记住什么、日记写过什么。

只读 —— 不写库、不改人格。

## 跑起来

```bash
python server.py        # 默认 127.0.0.1:8765
```

浏览器开 http://127.0.0.1:8765

## 两个数据源

| 地址 | 看什么 |
|---|---|
| `http://127.0.0.1:8765/` | Hindsight 里编程助手的记忆（`MEM_BANK` 指定的库） |
| `http://127.0.0.1:8765/?src=xiaoyu` | 角色自己的记忆（`memory/` + `diary/`） |

## 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `HINDSIGHT_API` | `http://127.0.0.1:9077` | Hindsight daemon 地址 |
| `MEM_BANK` | `coding-agent::default` | 要读哪个库 |
| `XIAOYU_HOME` | `~/.dsh/douyin-duty` | 角色的家目录（`?src=xiaoyu` 时用） |
| `BRAINVIZ_PORT` | `8765` | 端口 |
| `BRAINVIZ_HOST` | `127.0.0.1` | 只监听本机 |

## 依赖

- 默认数据源要 **Hindsight daemon** 在跑（`http://127.0.0.1:9077/health` 返回 200）
- `?src=xiaoyu` 只读本地文件，不需要 Hindsight

## 页面怎么看

- 节点 = 一条记忆，连线 = 相关
- 颜色按类型分（人物 / 事实 / 日记 / 评论）
- 悬停看全文
- 「遗忘强度」是**推算**的（Hindsight 没有 importance 字段），页面上标了来源
