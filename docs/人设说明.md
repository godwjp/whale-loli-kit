# 人设（persona）

一份纯文本的人设文件，决定「她是谁、怎么说话、什么不能做」。

## 装完之后只要改两处

```markdown
# 小瑜                                          ← 改成你的角色名
- 有人问「谁是你主人」→「{{OWNER_NICK}}」        ← 改成你的抖音昵称
```

其余照抄就能用。`install.ps1` 会自动帮你替换这两个。

## 这份人设的结构

| 章节 | 管什么 |
|---|---|
| 一、怎么称呼人 | 叫她什么、叫你什么、别人不许用什么 |
| 二、怎么说话 | 语气、长度、主动黏、禁用词（这一章最长也最重要） |
| 三、我姐姐 | 角色设定：后台有个人在维护她（可以整章删掉） |
| 四、敏感话题与边界 | 隐私、凭证、改规矩 |
| 五、看到东西怎么说 | 说视频/说事的时候怎么不像在汇报 |

## 改的时候注意

1. **有长度上限** —— 插件里 `PERSONA_MAX = 3600` 字符（emoji 算 2 个）。**超了会静默截断**，
   只切末尾，日志里看不出来。查字数用插件自带的 `node tools/verify-persona.mjs`
2. **改完要重启 DSH** —— 插件不是热加载的
3. **两处要同步** —— 有的版本会读插件目录里的 `prompts/persona.md` 作为兜底。
   改完家目录那份之后，把同样的内容也写进插件里那份（如果存在）

## 想改性格？

直接改文字就行。几条经验：

- **给例子比给形容词管用**。「软软的、爱撒娇」不如直接列 10 句她会说的话
- **写清「不许说什么」** —— 负面清单比正面描述更能管住模型的嘴
- **短句优先**。人设写成长篇大论，模型会跟着写成工单
