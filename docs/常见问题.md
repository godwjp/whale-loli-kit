# 常见问题（都是真踩过的）

---

## 人设改了没反应

三种可能，按顺序查：

1. **位置错了** —— `persona.md` 必须在 `%USERPROFILE%\.dsh\douyin-duty\` 根目录，不是插件目录里
2. **太长了** —— 插件里 `PERSONA_MAX = 3600` 字符（JS 按 UTF-16 算，一个 emoji 算 2 个）。
   **超了会静默截断**，只切末尾，日志里看不出来。
   查字数：`node tools/verify-persona.mjs`（插件自带）
3. **没重启** —— 插件代码不是热加载的，改完要重启 DSH

---

## 她「已读不回」

先分清是哪一种：

**A. 那一轮撞了连接错误**
症状：日志里出现 `Connection error` / `TRANSPORT`，重试 5 次后 `turn/end` 以 `error` 结束 ——
**一个字都没发出来**，而插件不会自动重跑。

这一类在较新版本里已经修了（投递后会起一个看门狗，45 秒后读一次会话事件，是 error 就自动重投一次）。
如果你的版本没有，手动补救：让对方再发一句，或者重启 DSH。

**B. 她自己决定不回**
人设里写死了几条硬边界，比如「要凭证（token / 密码 / 验证码 / Cookie）→ 一概不理」。
你发「token 来」，她会当成「要凭证」，直接不接。**这不是 bug，是设计。**

想区分 A 和 B：看日志里那一轮是不是 `completed` —— `completed` 就是她真的看过、决定不接。

## 重启后群里「乱说话」

老版本的 bug，症状：重启后她在群里把**以前问过的问题**重新答一遍。

原因：群消息走浏览器路径读，**没有时间戳**，判新只能靠一个「见过的文本数组」。
而那个数组以前**没落盘** —— 重启后它空了，于是**整段群历史都被当成新消息**。

修法（已在新版本里）：
- 那个数组跟着水位一起落盘（限 80 条）
- 老存档没有这个数组的群，强制「重新对表」（不重播）
- 每一拍都存一次

如果你遇到，先升级插件；升不了就手动删 `chat-watch-peers.json` 里群的那几条，
让它重新对表（会漏掉重启那一瞬间的消息，但不会重播历史）。

## 群消息读不到：「会话没打开（找不到输入框）」

群聊走的是**无头浏览器**路径（HTTP 接口只认 sec_uid，群过不去）。

常见原因：
- 浏览器实例卡住了 → 杀掉 `chrome-profile` 相关的进程，下一拍会自己重开
- 登录态过期 → 重新填 Cookie
- 抖音前端改版了 → 这个只能等插件更新

---

## Cookie 多久过期？过期什么表现？

大概几周~几个月，看抖音风控。

**过期表现**：
- 插件状态显示「未登录」
- 读取返回 401 / 提示登录
- 日志里 `AUTH: 401` / `Authentication Fails`

**重填**：F12 复制整行 Cookie，粘进设置页，重启 DSH。

## 记忆星图白屏 / 没数据

1. **Hindsight 没起** → 星图只读它，它没起来就没数据。
   检查 `http://127.0.0.1:9077/health` 有没有 200
2. **库名不对** → 默认 `coding-agent::default`，你的库名不一样就设环境变量：
   ```powershell
   set MEM_BANK=你的库名
   python brainviz/server.py
   ```
3. **看的是编程助手的记忆，不是角色的** → 加 `?src=xiaoyu`

## 生命状态面板数字不动

- 服务没起 → 看同目录 `vitals.log`
- 端口被占 → `netstat -ano | findstr 8781`
- 心跳停了 → 它靠 `state.json` 里最后时间算漂移，服务停了就不动了。重启服务即可

## Windows 上中文路径 / 中文输出乱码

这几条是血泪：

- **`.cmd` 批处理别放中文路径** —— cmd.exe 解析「纯 LF 换行 + GBK 中文」会读乱，
  报「不是内部或外部命令」。桌面入口用 **`.lnk` 快捷方式**（参数是 Unicode）
- **PowerShell 5.1 按 ANSI 读 UTF-8 无 BOM 的 `.ps1`**，会把中文注释弄乱。
  `.ps1` 里要么全 ASCII，要么存成 **UTF-8 with BOM**
- **别用 `Get-Content -Raw` + `Set-Content` 改 UTF-8 文件** —— PS5.1 按 GBK 读会毁掉中文。
  用 `[System.IO.File]::ReadAllText($p, [Text.Encoding]::UTF8)` + `WriteAllText`

## 改完配置什么时候生效？

| 改什么 | 怎么生效 |
|---|---|
| `persona.md` | 重启 DSH |
| `config.json` | 插件会自己读，但模型路由变了会**重建会话**（历史还在） |
| 插件源码 `index.js` | **必须重启 DSH** |
| `vitals.py` | 重启生命状态服务 |
| `brainviz/server.py` | 重启星图服务 |

## 它会不会把我的聊天记录传出去？

**不会。** 代码全是本地的：

- 采集：直接请求抖音接口（只读）
- 记忆：写在 `%USERPROFILE%\.dsh\douyin-duty\` 下的 JSON/Markdown
- 模型调用：走你自己配的 API

唯一的「出网」是：抖音接口 + 你配的模型 API。没有第三方服务器。

但**你的 API key 和 Cookie 是明文存在本机的** —— 别人拿到你这台机器就等于全拿到了。
