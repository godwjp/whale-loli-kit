# 安装指南（详细版）

> 跟着抄就行，每步都有「怎么确认它成了」。

---

## 0. 先确认三样东西都在

```powershell
node --version      # 要 v22 以上
python --version    # 要 3.9 以上
dsh --version       # DSH 桌面版，有输出就行
```

有一个没输出就先装那个，别往下走。

---

## 1. 装刷抖音插件

```powershell
# 方式 A：从 npm 装（如果有发布）
dsh plugin add dsh-douyin-scroll

# 方式 B：从源码装
git clone https://github.com/NEWJO123/dsh-douyin-scroll.git C:\Users\<你>\dsh-plugins\dsh-douyin-scroll
dsh plugin --profile web add link:C:\Users\<你>\dsh-plugins\dsh-douyin-scroll
```

**怎么确认成了**：重启 DSH → 设置页里能看到「刷抖音」这个插件 → 点开有配置项。

⚠️ 插件代码**不是热加载**的。改了插件源码、或者装完新插件，**必须重启一次 DSH** 才生效。

---

## 2. 跑安装脚本

```powershell
cd <这个仓库的目录>
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

它会问你两个问题：

| 问题 | 填什么 |
|---|---|
| 角色叫什么名字 | 你想叫她什么（回车 = 小瑜） |
| 你抖音号的昵称 | 用来回答「谁是你主人」这句话 |

**怎么确认成了**：`%USERPROFILE%\.dsh\douyin-duty\` 下面有 `persona.md` 和 `config.json`。

---

## 3. 填配置

打开 `%USERPROFILE%\.dsh\douyin-duty\config.json`，改这三处：

```jsonc
{
  "dmPeers": [
    { "nick": "你的抖音昵称", "sec_uid": "你的 sec_uid（可以留空，插件会自动补）" }
  ],
  "dutyRoute": "你的provider/你的模型",      // 值班会话用哪个模型
  "headlessRoute": "你的provider/你的模型",  // 后台轮次用哪个
  "pythonPath": "C:\\你的python路径\\python.exe"
}
```

`dutyRoute` / `headlessRoute` 的写法是 `provider/model`，provider 必须在你 DSH 的
`profiles/headless/cordis.patch.yml` 的 `providers` 里真的配了 —— 配不上，那一轮会直接挂。

---

## 4. 登录抖音

在插件设置页填 Cookie：

1. 浏览器打开抖音网页版，登录
2. F12 → Network → 随便点一个 douyin.com 的请求 → Request Headers → 复制**整行 Cookie**
3. 粘进插件的 Cookie 输入框

**怎么确认成了**：插件状态里显示你的抖音昵称，不是「未登录」。

⚠️ Cookie 会过期（大概几周到几个月）。过期表现是「读取失败 / 401」，重新复制一次就行。

## 5. 起两个本地服务

### 生命状态（8781）

```powershell
.\life-vitals\start-vitals.cmd
```

浏览器开 http://127.0.0.1:8781 能看到面板。

- 状态文件在同目录 `state.json`（**别提交进 git**）
- 换端口：`set VITALS_PORT=8888` 再启动
- 第一次启动会自己生成一份初始状态

### 记忆星图（8765）

```powershell
python .\brainviz\server.py
```

浏览器开 http://127.0.0.1:8765。

- `?src=xiaoyu` 看角色自己的记忆；不带参数看 Hindsight 的编程助手记忆
- 换库名：`set MEM_BANK=你的库名`
- 换端口：`set BRAINVIZ_PORT=8888`

## 6. 让它开机自启（可选）

Windows 上最省事的是「计划任务」：

1. Win+R → `taskschd.msc`
2. 创建任务 → 触发器「登录时」→ 操作「启动程序」
3. 程序填 `wscript.exe`，参数填你的 `.vbs`（没有就填 `.cmd`）

⚠️ **别让计划任务直接指向 `.cmd`** —— 每次会弹一个黑窗口。指向 `.vbs`（里面用
`WScript.Shell.Run` 隐藏窗口）才安静。

## 7. 验证一遍

| 检查 | 命令 / 位置 | 期望 |
|---|---|---|
| 插件活着 | DSH 设置页 | 显示你的抖音昵称 |
| 人设生效 | 私信里问「你是谁」 | 答角色名，不是「AI 助手」 |
| 生命状态 | http://127.0.0.1:8781 | 面板有数值，60 秒会动 |
| 星图 | http://127.0.0.1:8765 | 有节点图，不是白屏 |
| 记忆 | `%USERPROFILE%\.dsh\douyin-duty\memory\` | 聊几句后出现 `dm-*.json` |

## 装崩了怎么办

- **插件装不上** → 看 `dsh` 的输出，常见是 Node 版本太低或 profile 写错
- **人设不生效** → 检查 `persona.md` 是不是在 `douyin-duty\` 根目录，而且**没有超过 3600 字符**
- **服务起不来** → 看同目录的 `.log` 文件，多半是端口被占或 Python 路径不对
- **什么都没反应** → 先重启 DSH（插件不是热加载的）

实在不行：把 `%USERPROFILE%\.dsh\douyin-duty\` 整个备份一份，再从头装。
