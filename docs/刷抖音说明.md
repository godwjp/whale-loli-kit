# 刷抖音（douyin）

> ⚠️ **这一块的代码不在本仓库。** 它是独立插件
> [`dsh-douyin-scroll`](https://github.com/NEWJO123/dsh-douyin-scroll)（MIT）。
>
> 这里只放**配置模板**和**怎么配**。

## 为什么分开

那个插件本身有 8000+ 行、自带完整的 README / CHANGELOG / 测试，是一个独立项目。
把它复制进这个仓库会有三个问题：

1. 许可证和出处会乱
2. 你没法跟上游同步更新
3. 别人的数据（cookie / 好友 / 日报）更容易误提交

所以这里**只放配置模板**，插件用官方方式装。

## 装

```bash
dsh plugin add dsh-douyin-scroll

# 或从源码
git clone https://github.com/NEWJO123/dsh-douyin-scroll.git
dsh plugin --profile web add link:<克隆下来的目录>
```

装完**重启 DSH**。

## 配

把 `config.example.json` 复制到 `%USERPROFILE%\.dsh\douyin-duty\config.json`，改这几处：

```jsonc
{
  // 你自己的抖音昵称（私信/群聊盯梢都靠这个找人）
  "dmPeers": [
    { "nick": "你的抖音昵称", "sec_uid": "" }
  ],

  // 值班会话 / 后台轮次分别用哪个模型，写法 provider/model
  "dutyRoute": "你的provider/你的模型",
  "headlessRoute": "你的provider/你的模型",

  // 插件跑 Python 用哪个解释器
  "pythonPath": "C:\\你的python\\python.exe"
}
```

⚠️ `dutyRoute` 里的 provider **必须**在你 DSH 的
`profiles/headless/cordis.patch.yml` 的 `providers` 里真的配了 —— 配不上，那一轮会直接挂。

## 它做什么

| 会做 | 不会做 |
|---|---|
| 用只读接口取推荐流候选，按互动比值筛 | 不看视频画面（不截图、不 OCR、不做视觉） |
| 拉高赞评论作为判断依据 | 不做语音识别 |
| 写一份 Markdown 日报 | 不下载视频 |
| 可选：私信 / 分享卡片 / 回评论（默认**全关**，每道都有 `confirm` 闸） | 不代你登录 |

## ⚠️ 风险

- Cookie 等于**登录态**，别贴给别人、别在公共电脑用
- 自动化不是抖音官方功能，**可能违反用户协议，账号风险自担**
- 自动评论是**公开行为**，想清楚再开
- `.gitignore` 已经挡住 cookie / config / memory / diary / out，**push 前跑一次 `git status` 确认**

## 配置项速查

| 字段 | 作用 | 建议 |
|---|---|---|
| `perDay` | 每天最多跑几轮 | 50 |
| `autoEnabled` | 到点自动跑 | 想静默就先关 |
| `autoComment` | 自动评论 | **默认关**，了解清楚再开 |
| `autoSend` | 自动私信 | **默认关** |
| `chatWatch` | 盯私信/群聊，有新消息叫醒值班 | 开 |
| `chatWatchTarget` | 叫醒谁（`duty` = 值班会话） | `duty` |
| `lurkGroups` | 潜水群（只看不说话，被 @ 才接） | 按需 |
| `notifyMode` | 通知方式（`toast` / `webhook`） | `toast` |
| `reportLevel` | 日报详细程度 | `full` |
